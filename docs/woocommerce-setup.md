# WooCommerce: peruskonfiguraatio

Tämä dokumentti kokoaa WooCommerce-työn nykyiset peruslinjaukset ja niihin liittyvät erilliset toteutusdokumentit.

## Nykyiset WooCommerce-slicet

- Tampere 2026 -osallistumismaksutuote on dokumentoitu tiedostossa `docs/woocommerce-tampere-2026-product.md`.
- Tampere 2026 -checkout-kentät on dokumentoitu tiedostossa `docs/woocommerce-tampere-2026-checkout-fields.md`.
- Tampere 2026 -järjestäjäilmoitukset on dokumentoitu tiedostossa `docs/woocommerce-tampere-2026-notifications.md`.

## Tämän dokumentin tarkoitus

- pitää WooCommerce-kokonaisuus pieninä toteutussliceinä
- ohjata ylläpitoa oikeaan erillisdokumenttiin
- välttää liian suuren verkkokauppajärjestelmän rakentaminen kerralla

## Huomio

WooCommerce-toteutukset tehdään tässä projektissa kustannustehokkaasti ilman raskaita premium-lisäosia, ellei niille ole selkeää teknistä tai liiketoiminnallista perustetta.
